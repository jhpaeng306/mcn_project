## Evidence and assumptions

- The width matrix follows Billeh et al. (2020), Methods e10–e11. Their distance
  rule is `exp(-r²/s²)`, so our variance is `Sigma=(s/100)²/2` in `(0.1 mm)²`.
  Htr3a-to-VIP reduction and missing-pair substitutions remain assumptions.
- The reduced sign/zero motif follows Pfeffer et al. (2013). Exact zeros and
  the numerical integrated gains are effective-model assumptions. Connection
  probabilities alone do not identify normalized rate-model gains.
- The previous `G`, `tau=(10,12,35,20)` ms and population-specific sigmoid
  parameters are retained unchanged. No measured provenance is claimed for
  their exact numerical values.
- `L=43` = **4.3 mm** is a simple nearby domain choice. It gives the axial
  mode `k0=3` as the first instability on both the 1D and square tori;
  nearby integers 44–51 instead select oblique square modes. The spectrum
  comparison is saved in `output/main_literature/length_selection.json`.
- Frequency increases locally with wave number: `dω/dq≈+0.0471593` at onset.
  It is not globally increasing. The plots show all branches and rightmost
  branch switches.
- Default visual/thalamic input targets **E and PV**. Equal normalized strengths
  are an assumption. Ji et al. (2016) and Billeh's model support direct targeting
  of both populations. An E-only selective-input comparison is included in 1D.

Sources: [Billeh](https://doi.org/10.1016/j.neuron.2020.01.040),
[Pfeffer](https://doi.org/10.1038/nn.3446),
[Ji](https://doi.org/10.1093/cercor/bhv099).

## Three-population model

`make_model(3)` is the E/PV/SST block with **E→E strengthened 6.22009 → 6.72 (+8.04%)**;
widths, signs, zeros, `tau`, `g`, `theta` are unchanged. The unmodified block
(`make_model(3, submatrix=True)`) has a homogeneous first Hopf onset. With the change,
the recomputed onset is `kappa_c≈0.5880341657`, `k0=3`, `f0≈9.541 Hz`, and
`dω/dq≈+0.00404988` mm/ms. It is analyzed in 1D only (Section 7 of `analysis.ipynb`),
because on the square torus the oblique shell `|k|²=8` crosses first. It uses the same
forcing peaks as four populations, over 300 s. Its spatial input acts on the `A=-B`
branch with threshold ≈26.6, so spatial peak 8 is subthreshold. Outputs are in
`output/main_literature/3pop_1d/`. Run with `--dim 1 --K 3`.

## Numerical setting

`J=kappa*G`, with `kappa_c≈0.7491489065`. The report coordinate is
`p=kappa-kappa_c`; the solver uses absolute `kappa`. Below-onset runs use
`epsilon=.02`, `p=-epsilon²`.

Temporal/spatial cosine peaks are `epsilon²` times `(3,0)`, `(0,8)` or `(3,2)`;
the traveling cosine peak is `2 epsilon²`. These choices follow the amplitude
threshold/stability inequalities, recomputed for the restored model.
The weak temporal control uses peak `epsilon²`.

RK4 uses 1-ms time steps, 150-s duration, 64 cells in 1D and 32×32 in 2D.
Reflecting boundaries use DCT-II convolution and their own onset calculation.
The unchanged three-population block has a homogeneous first Hopf onset;
it is not advertised as a finite-wave example or silently retuned.

Use `--recompute` or notebook `RECOMPUTE=True` to rerun the fields. Otherwise,
only caches matching the complete model, input targeting, forcing, boundary,
grid, duration and time step are reused.

Current outputs are under `output/main_literature/4pop_1d/` and `4pop_2d/`:

- `settings_*.json`: model, forcing and numerical settings.
- `field_*.npz`: initial/final fields, modal histories, 1D E histories,
  sparse and late all-population snapshots, and cache fingerprints.
- `summary*.json`: measured amplitudes, frequencies and spectral checks.
- PNG files: embedded notebook figures. Full-duration 1D panels show 100-ms RMS;
  late-time panels show signed activity.
